    Prompt de Comando

    Algumas curiosidades sobre o Prompt de Comando

    Imagine ter um superpoder escondido no seu computador, capaz de realizar tarefas rapidamente sem precisar clicar em dezenas de botões. Esse é o Prompt de Comando do Windows! O Prompt de Comando é uma interface de linha de comando do Windows que permite aos usuários interagir com o sistema operacional por meio de comandos de texto. Ele funciona como um interpretador de comandos, permitindo executar tarefas como gerenciamento de arquivos, configuração de rede, diagnóstico do sistema e automação de processos.
    O prompt de comando do windows por exemplo é considerado CMD e ele permite executar instruções diretamente do proprio espaço de código do windows, ou seja, o interpretador. Aí pode-se utiliza várias ferramentas e até instalar programas que rodem diretamente do prompt de comando

    Prompt de Comando do Windows (CMD)

    Existem vários prompts de comando, variando do sistema operacional e do próprio computador. O prompt de comando do windows, bem como mencionado anteriormente é chamado de CMD que significa "Command Prompt", que em português pode ser traduzido como "Prompt de Comando" em português.
    O CMD é essencial para executar comandos administrativos, diagnosticar problemas, automatizar tarefas e acessar configurações avançadas do sistema.

    Alguns comandos do CMD

    echo
    Serve para exibir uma mensagem. Por exemplo:
    echo Hello World -- Isso irá permitir exibir a mensagem Hello World
    cls
    Esse comando permite limpar a tela do terminal. Por exemplo ao digitar muitos textos no terminal e prentendes limpar, use o cls
    ipconfig
    Esse comando mostra os detalhes da rede IP
    systeminfo
    Mostra informações detalhadas do sistema. Por exemplo, se queres saber a capacidade do seu computador, a sua placa de rede, e muitas outras informações
    tasklist
    Aqui podes listar os processos em execução, como programas e tudo mais
    netstat -an
    Exibe conexões de rede ativas, ou seja, para ver quais são os dispositivos que estão conectados à sua rede
    taskkill /F /IM [Nome do processo]
    Esse cmando finaliza um certo processo diretamente do CMD
    cd
    Permite acessar a uma certa pasta. Por exemplo: cd Pasta1 Para acessar a "Pasta1"
    cd..
    Para sair de uma certa pasta, por exemplo: cd.. Pasta1 Desta forma sai da "Pasta1"

    Comandos Extra
    winget install nome_do_programa
    Esse comando permite Instalar um certo programa ou uma certa funcionalidade no computador. Como por exemplo winget install Google.Chrome Para instalar o Google Chrome
    winget install nome_do_programa --silent
    Permite fazer instalação sem janela de confirmação
    set /a resultado=x+y
    Permite fazer cálculos matemáticos. por exemplo, calcular 5 + 8: set /a resultado=5+8 O resultado é 13
    start nome_do_programa
    Para executar um certo progama usa-se esse comando. Por exemplo se quiser usar a calculadora pode digitar start calc Isso abrirá a calculadora

    Interpretador

    Um interpretador é um programa que lê e executa o código-fonte de uma linguagem de programação linha por linha, sem precisar convertê-lo previamente em um arquivo executável. Como é o exemplo do prompt de comando.

    Que linguagem de programação usa o CMD?

    O CMD não usa exatamente uma linguagem de programação, mas sim um interpretador de comandos que usa uma linguagem de script chamada Batch Script (arquivos .bat). Essa linguagem permite automatizar tarefas e executar comandos do sistema operacional.


    Além do Batch Script, o Windows também suporta PowerShell, que é uma linguagem de script mais avançada baseada no .NET, permitindo automação mais poderosa e interações com APIs do sistema.

    Mudar a Cor dos códigos

    color 02

    Personalização do CMD

    Você pode personalizar o CMD (Prompt de Comando) do Windows para deixá-lo com uma aparência mais agradável e funcional. Aqui estão algumas maneiras de fazer isso:

    1. Alterar a cor da área de código do CMD:

    - Você pode alterar a cor do texto e do fundo diretamente com o comando color

    Por exemplo: color 0A Isso muda o fundo para preto e o texto para verde.

    2. Para ver todas as opções de cores, digite:

    - color /?

    3. Criar um título personalizado:

    - Você pode usar o comando title para mudar o nome da janela do CMD: . Exemplo: title Meu CMD Personalizado

    4. Usar temas avançados

    - Também podes ter noções mais detalhadas de como personalizar o seu CMD. Se quiser uma personalização mais profunda, pode usar o Oh My Posh, que permite criar temas coloridos para o CMD e PowerShell. Veja como configurar
